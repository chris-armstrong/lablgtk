# ocgtk — OCaml Bindings for GTK 4

ocgtk provides idiomatic OCaml bindings for GTK 4, generated from
GObject Introspection (GIR) data.

## Features

- Comprehensive GTK 4 widget bindings
- GObject type system integration
- Signal and property support
- GDK, GIO, Pango, Cairo, and GSK sub-library bindings
- High-level wrapper classes for ergonomic OCaml usage

## Requirements

- GTK 4 (via `conf-gtk4` system package)
- OCaml >= 4.14
- dune >= 3.21
